# 02. 히트맵에 경기장 넣기

**무엇을:** 경기 뒤 히트맵 위에 실제 경기장 라인을 그려, 심판이 "박스 앞이었는지, 터치라인 쪽이었는지"를 보며 자기 위치 선정을 돌아볼 수 있게 했다.

**왜 이렇게:** GPS 경로로 경기장 네 모서리를 추정해 미리 놓고, 사용자는 위성 사진을 보며 점을 끌어 고치기만 한다. 학교 운동장은 크기가 제각각이라 정규 크기로 맞추지 않고 찍은 그대로 쓴다. "그려진 라인이 실제와 어긋나 판단을 틀리게 만드는 것"을 실패 조건으로 먼저 정했다.

**순서:**
1. [design.md](design.md) — 사용자 요구, 하지 않을 것, 실패 조건, 정해진 것. (설계 당시 검토한 브이월드 항공사진은 이후 쓰지 않기로 했고, 한국 경기의 위성 사진은 나중에 네이버 지도로 바꿨다.)
2. [plan.md](plan.md) — 경기장 추정·좌표 변환은 공유 모듈(Swift·Kotlin)에, 맞추기 화면은 각 앱에 나눈 작업 계획.
3. [checklist.md](checklist.md) — 실제 경기장·GPS로만 확인할 수 있는 항목.

추정·좌표 계산 코드는 이 저장소의 `RefereeSession`(Swift)과 `android/session`(Kotlin)에 있다.
